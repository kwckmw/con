# con · Groundline 토공 현장 관제 시뮬레이터

공사현장을 3D로 보여주는 관제 화면입니다. 굴삭기 2대, 덤프트럭 6대, 타워크레인이 실제처럼 움직이고, 굴착한 흙이 트럭에 실려 사토 야적장에 쌓입니다. 단일 HTML 파일로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. three.js r128을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 주요 기능

- **굴삭기 HX220A × 2**: 바닥 높이 격자를 읽어 가장 높은 곳부터 팝니다. 역기구학으로 붐·암·버킷 각을 계산하고, 버킷 날이 지나간 자리만큼 흙이 깎입니다. 구간을 다 파면 직접 판 경사로를 따라 0.9 m씩 3번 내려갑니다.
- **덤프트럭 HA30A × 6**: 굴절식 조향, 적재함 덤프(최대 70°). 북측·남측 두 운반로를 돌며, 크레인 앞 공용 덤프로의 합류 구간은 한 번에 한 운반로만 진입합니다. 앞차와 정지 간격은 5 m 이상입니다.
- **타워크레인**: PC 기둥과 슬래브를 양중해 6층 골조를 올립니다.
- **대시보드**: KPI, 장비 상세 패널, 트럭 트래커, 알림, 배속(1~32×), 주야간, 안전반경 표시.
- **직접 운전**: 화면 조이스틱 또는 키보드(ISO 조작 방식), 운전석 시점.
- **투어**: 7개 장면을 도는 시네마틱 카메라.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성본 (빌드 결과) |
| `build.py` | `src/` 조각을 합쳐 `index.html`을 만드는 스크립트 |
| `src/tpl.html` | 화면 틀 (CSS, 대시보드 요소) |
| `src/core.js` | 렌더러·조명, 높이 격자, 운반로 계산 |
| `src/world.js` | 구덩이, 지층 벽, 운반로, 야적장, 시설물 |
| `src/truck.js` | HA30A 덤프트럭 모델 |
| `src/traffic.js` | 트럭 운행, 합류 구간 통제, 충돌 검사 |
| `src/excav.js` | 역기구학, 굴착 계획, 단계별 하강 |
| `src/crane.js` | 타워크레인, PC 골조 양중 |
| `src/main.js` | 패널, 직접 운전, 투어, 메인 루프 |
| `src/factory.js` 외 | HX220A 굴삭기 모델 (`lower2.js`, `upper.js`, `work2.js`, `util.js`, `hxd.js`) |

## 빌드

```bash
python3 build.py
```

표준 라이브러리만 사용합니다. `src/`를 고친 뒤 실행하면 `index.html`이 다시 만들어집니다.

## 참고와 한계

- 장비 수치는 공개 사양을 따릅니다 (HX220A 카탈로그, HA30A 적재 28 t · 적재함 16.8 m³ · 덤프각 70° · 회전반경 7.68 m). 공개되지 않은 치수는 사진 비례로 추정했습니다.
- 굴삭기는 지상 트럭에 실어야 해서 3단(−2.7 m)까지만 내려갑니다. 더 내려가면 덤프 높이가 모자랍니다 (HX220A 최대 덤프 높이 6.9 m).
- 야적장 길 위에 쏟은 흙은 도저 정리를 가정해 더미 쪽으로 옮겨지며, 도저 모델은 없습니다.
- 두 굴삭기가 모두 끝나면 시연용으로 구덩이와 야적장을 처음 상태로 되돌립니다.
