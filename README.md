# con · Groundline 토공 현장 관제 시뮬레이터

공사현장을 3D로 보여주는 관제 화면입니다. 기존 굴착 현장(굴삭기 · 덤프트럭 · 타워크레인) 동쪽에 성토장, 노반 정지 구간, 관로 굴착 구간을 붙여 현장을 약 두 배로 넓혔고, 장비 7종이 각자 맡은 일을 합니다. 화면 위 장비 막대에서 종류별 대수를 바꿀 수 있습니다. 단일 HTML 파일로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. three.js r128을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 장비와 작업

| 장비 | 대수 (기본) | 하는 일 |
|---|---|---|
| 크롤러 굴삭기 HX220A | 1~2 (2) | 구덩이를 단계별로 파서 덤프트럭에 싣는다. 직접 운전 가능 |
| 덤프트럭 HA30A | 2~8 (6) | 두 운반로를 돌며 사토 야적장에 쏟는다. 합류 구간은 한 운반로씩 진입 |
| 휠 굴삭기 | 0~3 (2) | 아웃트리거와 블레이드를 내리고 깊이 1.6 m 관로를 판다. 다 파면 다리를 접고 2.2 m 물러난다 |
| 휠로더 | 0~4 (2) | 토사 적치장에서 3 m³씩 퍼서 Y자 주행(후진 → 방향 전환 → 전진)으로 성토장 띠 끝에 붓는다 |
| 스키드로더 | 0~3 (2) | 모래 칸에서 퍼다가 파 놓은 관로 바닥에 기초 모래를 깐다 |
| 도저 | 0~3 (2) | 성토장 띠 끝의 흙더미를 계획고(층 두께 0.3 m)에 맞춰 펴 고른다 |
| 모터 그레이더 | 0~2 (1) | 거친 노반을 줄지어 왕복하며 평탄하게 고른다 |
| 타워크레인 | 1 (고정) | PC 기둥과 슬래브를 양중해 6층 골조를 올린다 |

- **장비 막대**: 화면 위 아이콘 옆 − / + 로 대수를 바꾼다. 줄이면 그 장비가 현장에서 빠지고, 덤프트럭은 싣고 있던 흙을 쏟은 뒤 빠진다. 크롤러 굴삭기를 1대로 줄이면 남측 운반로가 쉬고 트럭은 최대 4대가 된다.
- **흙은 실제로 움직인다**: 구덩이, 사토 야적장, 성토장, 적치장, 노반, 관로가 모두 높이 격자다. 버킷과 블레이드가 지나간 만큼 깎이고, 부은 만큼 쌓이며, 안식각을 넘으면 흘러내린다.
- **서로 피한다**: 휠로더는 다른 휠로더의 선회 범위와 겹치면 출발하지 않고, 도저가 작업 중인 띠에는 붓지 않는다. 도저는 이웃한 띠끼리 묶어 맡는다. 스키드로더는 휠 굴삭기 작업 반경(11 m) 밖에서만 관로에 접근한다.
- **대시보드**: KPI, 장비 상세 패널, 트럭 · 장비 트래커, 알림, 배속(1~32×), 주야간, 안전반경 표시.
- **직접 운전**: 크롤러 굴삭기를 골라 화면 조이스틱 또는 키보드(ISO 조작 방식)로 운전, 운전석 시점.
- **투어**: 11개 장면을 도는 시네마틱 카메라.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 완성본 (빌드 결과) |
| `build.py` | `src/` 조각을 합쳐 `index.html`을 만드는 스크립트 |
| `src/tpl.html` | 화면 틀 (CSS, 대시보드 요소, 장비 막대) |
| `src/core.js` | 렌더러 · 조명, 높이 격자(깎기 · 쌓기 · 메우기 · 고르기), 운반로 계산 |
| `src/world.js` | 구덩이, 지층 벽, 운반로, 야적장, 시설물, 확장 구역 경계 |
| `src/truck.js` | HA30A 덤프트럭 모델 |
| `src/fleet.js` | 휠로더 · 스키드로더 · 도저 · 그레이더 · 휠 굴삭기 모델 (분해도 모델의 형상과 기구학을 옮긴 것) |
| `src/traffic.js` | 트럭 운행, 합류 구간 통제, 충돌 검사 |
| `src/excav.js` | 크롤러 굴삭기 역기구학, 굴착 계획, 단계별 하강 |
| `src/crane.js` | 타워크레인, PC 골조 양중 |
| `src/site2.js` | 동측 확장 구역의 지형과 장비 자동 작업 (경로 주행, 작업 순서, 구역 잠금) |
| `src/main.js` | 대수 조정, 패널, 직접 운전, 투어, 메인 루프 |
| `src/factory.js` 외 | HX220A 굴삭기 모델 (`lower2.js`, `upper.js`, `work2.js`, `util.js`, `hxd.js`) |

## 빌드

```bash
python3 build.py
```

표준 라이브러리만 사용합니다. `src/`를 고친 뒤 실행하면 `index.html`이 다시 만들어집니다.

## 참고와 한계

- 크롤러 굴삭기와 덤프트럭의 수치는 공개 사양을 따릅니다 (HX220A 카탈로그, HA30A 적재 28 t · 적재함 16.8 m³ · 덤프각 70° · 회전반경 7.68 m). 공개되지 않은 치수는 사진 비례로 추정했습니다.
- 새로 넣은 장비는 일반적인 구조를 단순화한 모델입니다. 크기는 공개 제원의 전장과 궤간에 맞췄고(스키드로더 HSL850-7A, 도저 HD100, 그레이더 HG170-3), 휠로더는 현장 크기에 맞춰 25톤급으로 줄였습니다. 휠 굴삭기는 HX220A 상부에 바퀴식 하부를 붙인 것이라 실제 휠 굴삭기보다 큽니다.
- 주행 경로는 시작과 끝 방향을 잇는 곡선을 따라가는 방식이라, 급하게 꺾이는 자리에서는 바퀴가 조금 미끄러져 보일 수 있습니다. 도저와 그레이더는 줄을 바꿀 때 후진하며 비스듬히 옮겨 갑니다.
- 대수를 늘린 직후에는 새 장비가 기존 장비와 잠깐 겹쳐 보일 수 있습니다. 서로 막힌 채 10초가 지나면 번호가 빠른 쪽이 먼저 지나갑니다.
- 시연이 끊기지 않도록 되돌리는 것들: 적치장은 외부 반입을 가정해 줄어들면 다시 채워지고, 성토장은 4층(1.2 m)이 차면 비워지며, 노반은 다 고르면 다시 거칠어지고, 관로는 구간을 다 파면 되메워집니다. 구덩이와 야적장도 굴착이 끝나면 처음 상태로 돌아갑니다.
- 크롤러 굴삭기는 지상 트럭에 실어야 해서 3단(−2.7 m)까지만 내려갑니다 (HX220A 최대 덤프 높이 6.9 m).
- 사토 야적장 길 위에 쏟은 흙은 도저 정리를 가정해 더미 쪽으로 옮겨집니다 (이 구역에는 도저 모델을 배치하지 않았습니다).
